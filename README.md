Java Apache Projects

Repositório com exercícios e trabalhos práticos de Java desenvolvidos ao longo do curso de Engenharia Informática.Estrutura do repositório
Cada pasta (ex1, ex2, ..., projeto_1, projeto_2, ..., trab_pratico_final, etc.) é um projeto Java independente, com o seu próprio código-fonte e ponto de entrada (main).

Requisitos:
  1. Java 23 (JDK)
  2. Visual Studio Code
  3. Extensões do VS Code:
        Extension Pack for Java (Microsoft)
        Debugger for Java (Microsoft)


Como abrir e correr os exercícios:

Como cada pasta é um projeto separado, é preciso abrir os exercícios um a um — não abrir a pasta raiz do repositório como projeto único, aqui esta passo a passo para abrir cada um:
    1. Abrir o VS Code.
    2. File > Open Folder e selecionar a pasta do exercício/projeto pretendido (ex: ex3 ou projeto_2).
    3. Com as extensões de Java instaladas, o VS Code detecta automaticamente a classe com o método main.
    4. Correr com o botão Run por cima do método main, ou F5 para correr com o debugger.



    
Notas:
Cada pasta é independente das restantes — não há dependências entre projetos.
Consultar o README.md dentro de cada pasta (quando existir) para detalhes específicos desse trabalho.
No final tem o trabalho geral final da disciplina com um pdf referente ao trabalho, o resto dos exercícios foram dados com base em preguntas feitas nas aulas.
